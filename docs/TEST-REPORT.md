## 3. أخطاء وُجدت أثناء الاختبار ثم عُيّنت

| # | الخطأ | الأثر | الإصلاح |
| --- | --- | --- | --- |
| 1 | رسالة «تمّت قراءة الأذكار كلها» تظهر دائمًا | يكذب على المستخدم | تظهر فقط عند `done >= total` |
| 2 | تبويب المفضلة يعرض كل الأذكار | الميزة بلا معنى | استخدام `filterFavorites` + تصحيح اتجاه رسالة التأكيد |
| 3 | زر المشاركة يفشل حين يُمنع Clipboard API | لا نسخ | سلسلة بدائل: Clipboard API ← `textarea` + `execCommand("copy")` |
| 4 | **عامل الخدمة لا يُسجَّل أصلًا** | لا وضع دون اتصال إطلاقًا | كان يبني المسار من `import.meta.url` إلى `/assets/sw.js` (404) — صار `register("./sw.js", { scope: "./" })` |
| 5 | السلسلة/العدد مدى الحياة صفرًا رغم وجود تقدّم | إحصاءات خاطئة | حسابها من ملخّص اليوم لا من السجلّ وحده |
| 6 | الترويسة تقرأ الثيم من DOM (متأخّر دورة) | وميض خاطئ | إضافة `resolvedTheme` محسوبة في السياق |
| 7 | **لا واجهة لهدف مخصّص** | شرط مفقود | محرّر كامل في البطاقة + حفظ الأهداف عبر تبدّل اليوم |
| 8 | رابط التخطّي `#main` يصارع HashRouter | ينقل للمسار الخاطئ | `preventDefault` + نقل تركيز مؤجّل |
| 9 | 502 من وسيط الشبكة يمرّ إلى المستخدم | وضع دون اتصال لا يعمل | يُعامل أي ردّ غير `ok` كتعذّر ويرجع للنسخة المحفوظة |
| 10 | مطابقة الـ cache تفشل بعد إعادة التحميل (`Vary`) | الأصول (JS/CSS) تفشل رغم وجودها محفوظة | `ignoreVary: true` في كل المطابقات |
| 11 | **Lighthouse: ترتيب عناوين h1→h3** | إخفاق إمكانية الوصول | عناوين البطاقات `h3→h2` والمصادر `h4→h3` |
| 12 | **Lighthouse: اسم زر ≠ نصه الظاهر** («هدف مخصّص» مقابل aria-label طويل) | إخفاق إمكانية الوصول | أُعيدت صياغة `aria-label` ليبدأ بنصه الظاهر |

بعد الإصلاحات: **Lighthouse 100/100/100 بلا أي إخفاق على المسارات الستة**،
و`test:e2e` يرفع إلى **90 فحصًا** بإضافة فحوص تمنع تراجع بنود 9–12.

## 5. القيود المعلومة قبل النشر

1. **الصوت والتذكيرات يحتاجان إنترنت** (أو وجود التطبيق مفتوحًا) — لا يمكن تضمينهما
   بلا ملفات صوتية مستضافة ذاتيًا و/أو خدمة Push.
2. **عامل الخدمة لا يعمل على HTTP غير `localhost`** — انشر على HTTPS.
3. **`localStorage` يخص الجهاز والمتصفح** — لا مزامنة بين الأجهزة (بلا خادم، وهو قرار مقصود).
4. **الترجيح بين «حصن المسلم» وsunnah.com غير محسوم** في ثلاثة أذكار — معروض
   للمستخدم لا مخفي. التفاصيل: [`CONTENT-VERIFICATION.md`](CONTENT-VERIFICATION.md).
5. **الأرقام غير المُتحقَّق منها (27)** تظهر دائمًا بتسمية تنبّه — لن تُقرأ يومًا على
   أنها موثّقة.

## 6. كيف تعيد الاختبار بنفسك

```powershell
npm.cmd install
npm.cmd test            # بيانات + بناء + 90 فحصًا
npm.cmd run test:data -- --network   # فحص حي للروابط (يحتاج إنترنت)
npm.cmd run preview     # ثم افتح http://localhost:4173
```

**لإثبات وضع دون اتصال:** افتح الموقع مرة، ثم أوقف الخادم (`Ctrl+C`) وأعد التحميل —
يجب أن يظهر الموقع كاملًا بلا أخطاء في الطرفية.
