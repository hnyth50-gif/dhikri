# لقطات الاستعادة (Snapshots)

> **الهدف:** أن يبقى لكل تغيير نقطة عودة مفهومة — مؤرَّخة ومشروحّة — حتى لو
> حدث تغيير غير مرغوب، فتُستعاد الحالة السابقة بخطوات قليلة ومُختبَرة.

## كيف تُحفظ اللقطات

### 1) تلقائيًا مع كل commit (بلا أي إجراء)

الملف `scripts/hooks/post-commit` (وأصله المُثبَّت في `.git/hooks/post-commit`)
يُنشئ عند **كل commit** وسمًا مُعلقًا اسمه:

```
snap-auto-<YYYYMMDD-HHMMSS>-<معرف الـcommit>
```

ورسالته = **عنوان الـcommit (أي شرح التغيير) + التاريخ**. فكل تغيير يُحفظ لحظة
حدوثه ومعه تعليق يشرحه وتاريخه. الـhook يخرج دائمًا برمز نجاح ولا يُفشل عملية
الحفظ أبدًا مهما أخطأ.

إذا استنسخت المستودع من جديد فثبّت الـhook مرة واحدة:

```powershell
Copy-Item scripts/hooks/post-commit .git/hooks/post-commit   # PowerShell
cp scripts/hooks/post-commit .git/hooks/post-commit          # sh
```

### 2) لقطة موثّقة يدويًا (تُفضَّل بعد كل ميزة مُختبَرة ومُسلَّمة)

```powershell
npm run snapshot -- "شرح ما تغيّر"
```

تضيف إدخالًا إلى «سجل اللقطات» أسفله (التاريخ + الوسم + الشرح)، وتنشئ وسمًا
مُعلقًا رسالته = ذلك الشرح والتاريخ، **وتكتب أرشيف zip مستقلًا** في مجلد
`snapshots/` (خارج git ومُزامَن مع OneDrive) كنسخة احتياطية لو تلف سجل git.

> ملاحظة: اللقطة تمثّل حالة الـ**commit**؛ التعديلات غير المُحفوظة بعد لا
> تدخلها — وهذا أقصد، لأن اللقطة تكون لحالة محفوظة ومعروفة قابلة للتكرار.

## كيف تستعيد لقطة

```powershell
# 1) عرض اللقطات (الأحدث أولًا)
git tag --sort=-creatordate -l "snap*"

# 2) الاطّلاع على لقطة دون تغيير أي ملف
git show snap-2026-10-17-01 --stat

# 3) استعادة على فرع مؤقت (آمنة — main لا تتغيّر)
git switch -c preview-snapshot snap-2026-10-17-01
git switch main
git branch -D preview-snapshot

# 4) استعادة فعلية على main — احتراس: تُغيّر التاريخ وتُعيد النشر
git status                      # يجب أن تكون نظيفة
git reset --hard snap-2026-10-17-01
npm run test                    # تأكد من كل الاختبارات قبل الدفع
git push --force-with-lease     # إرجاع الموقع الحي للحالة القديمة
```

إن أردت إلغاء تغيير واحد فقط دون إعادة كتابة التاريخ: `git revert <commit>`.

**الأرشيف المستقل:** لو تلف سجل git، فكّ `snapshots/<الوسم>.zip` واستبدل
الملفات يدويًا (المجلدات المُتّجهة: `src` و`public` و`scripts` و`docs`
وملفات الإعداد في جذر المشروع).
